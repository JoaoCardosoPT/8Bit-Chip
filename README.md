# CHIP-8 Emulator

A CHIP-8 emulator written in C with a 64KB memory
## Overview 

These emulator loads a binary program into memory and executes its instructions 
through a fetch–decode–execute loop

## Features

-> 64 KB of byte-addressable memory
-> Eight 8-Bit Register: R0-R7
-> A 16-bit program Counter (PC)
-> Instructions for loading values, adding, and halting
-> Write protection for lower memory region
-> Binary Program Loading
-> Really Basic Assembler and disassembler Functions
